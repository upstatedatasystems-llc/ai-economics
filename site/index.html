07 / EVIDENCE & LIMITS

How trustworthy is each input?

Published reference

Consumer plans, API schedules, GPU rental price, electricity and facility-efficiency references.

Transparent assumption

Calls per task, throughput, workload size, hidden output, caching, staffing, fleet utilization and overhead.

Not disclosed

Actual provider cost, proprietary model throughput, routing, subsidies, per-user ad revenue and most tool economics.

Method and limitations

We convert one task's input and generated tokens into API charges at published rates. For compute, we turn input and output into an output-equivalent GPU workload and allocate costs at assumed throughput and utilization. We then add fleet-allocated staffing and administration. Cloud rental and owned infrastructure are alternative cost models. The same shared hardware proxy currently applies to each provider; we do not claim provider-specific inference efficiency.

Inputs in the examples are illustrative, not statistically typical or measured transcripts. Different models can require different numbers of calls and tokens for the same work. For coding workflows, unpriced external tools may materially increase cost. Future research ingestion will attach model-specific performance benchmarks and reproducible traces.
